MOSH Social Hub — ملاحظة الربط الخارجي

الواجهة الحالية مستقلة عن المهام حسب القرار المعتمد.
يمكن حفظ تعريف حسابات العميل ومسودات وجدولة المحتوى داخل MOSH.
النشر الفعلي إلى Instagram/Facebook/TikTok/LinkedIn يحتاج:
- HTTPS على عنوان MOSH العام.
- تطبيق مطور رسمي لكل مزود.
- App ID / Client ID وApp Secret من المزود.
- Redirect URI معتمد.
- صلاحيات النشر/إدارة الصفحات التي يوافق عليها المزود.

لا تضع كلمات مرور صفحات السوشال داخل MOSH.
