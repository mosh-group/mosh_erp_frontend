# MOSH R18 — إصدار اللوحة المصغرة المتصلة بالنظام

## نطاق التعديل
بُني الإصدار من MOSH_R17_SHORT_PATH_3_PACKAGES.zip مباشرة. أُضيف اختصار بجانب الخروج، ولوحة عائمة داخل التطبيق ونافذة متصفح مستقلة مع شريط مصغّر واستعادة الحجم. لا يوجد وضع DEMO، ولا حسابات تجريبية جديدة، ولا محاكاة API في ملفات التشغيل المضافة.

اللوحة تقرأ إسقاطاً للعرض من MoshWorkdesk50.miniSnapshot؛ البدء والاستلام والإيقاف والاستراحة والتبديل كلها تستدعي MoshWorkdesk50.perform الأصلي. لا تُخزّن جلسات تنفيذ بديلة في localStorage ولا تعدّل مدة المهمة محلياً. يقتصر سجل localStorage الجديد على إشعار خروج يتضمن هوية الحساب والتوقيت، دون كلمات مرور أو رموز جلسة.

ملفات التشغيل الجديدة: css/r18-mini-workdesk.css وjs/63-mosh-mini-workdesk.js.

في auth أضيف الاختصار وإشارة خروج بعد تأكيد الخادم. في workdesk أضيفت قراءة للعرض وتنظيم تحديث النوافذ الأخرى حتى لا يمسح نموذجاً غير محفوظ. لم يُستبدل منطق المعاملات أو التوقيت أو الصلاحيات. manifest أصبح 64 سكربتاً. أرقام كاش loader والملفات المعدلة مُحدثة دون إعادة preload.

نجحت 32 من 32: الاختصار، المهام الشخصية، بدء بوقت الخادم، حفظ الإيقاف، عدم تراكم التوقف، تبديل ذري إلى مهمة واحدة، الاستراحة وعدم وجود عمل، استلام دون بدء، ضياع رد الحفظ مرتين مع بقاء نفس مفتاح المعاملة، منع التكرار ثم حل حالة الحفظ غير المؤكد، سجل اليوم، إنهاء العمل، النافذة المستقلة، استرجاع الفترات من SQLite، الاستمرار بعد إغلاق الصفحة الأساسية، انقطاع الشبكة، حماية المسودات، والشاشة الضيقة. لا أخطاء JavaScript غير معالجة.

## حدود الفحص المهمة
1. بيئة المختبر Linux مع PHP 8.4.23، بينما المشروع يشترط PHP ^8.5. تجاوز حارس النسخة حصل في مجلد مختبر معزول حصراً؛ لا تعديل في composer أو vendor داخل التسليم.
2. لا يتوفر pdo_sqlite في المختبر؛ شُغّل Laravel باستخدام محول PDO خاص عبر FFI إلى libsqlite3 الحقيقي. SQL والمعاملات والملف حقيقية، لكنه ليس مشغل PDO الأصلي. المحول غير مرفق بإصدار النشر.
3. سياسة متصفح المختبر تمنع الملاحة إلى عناوين الشبكة. شُغّلت ملفات HTML/CSS/JS الفعلية ضمن about:blank وناقل HTTP إلى Laravel عبر requests.Session. إنشاء popup/resizeTo حقيقي؛ بدل عنوان النافذة في harness هو about:blank?moshMini=1. هذا لا يختبر CORS/Cookies على عنوان الإنتاج أو متصفح المستخدم، ولا يختبر HTTPS/reverse proxy.
4. لا اختبار لجهاز Windows أو البصمة الحقيقية أو انقطاع أيام/ضغط عدد كبير من المستخدمين. لا يعني النجاح أن جميع أقسام ERP بلا عيوب.
5. نافذة المتصفح ليست تطبيقاً أصلياً دائماً فوق Photoshop ولا أيقونة نظام؛ لا يوجد EXE جديد في هذه الحزمة. Browser resize قد يُقيّد على التبويبات العادية والموبايل. المرجع الرسمي: MDN Window.resizeTo وWindow.open.
