MOSH ERP — R17 — صلاحيات أوضح + ضبط مظهر منفصل + دخول/خروج أسرع
================================================================

هذه النسخة مبنية على R16 المدموجة مع ZKTeco.
طريقة التركيب للمستخدم: استبدال حزم/مجلدات المشروع بنفس الطريقة المعتادة دون أوامر إضافية.

أهم الجديد:
1) صلاحية جديدة مستقلة: «ضبط المظهر والخطوط».
   - تسمح بالخط، أحجام الكتابة، الألوان وراحة الواجهة فقط.
   - لا تسمح بإدارة الحسابات أو تعديل الصلاحيات.
   - لا تسمح بتعديل اسم النظام/الشركة أو سياسات HR.
2) «إدارة الحسابات» و«تعديل الصلاحيات» بقيتا صلاحيتين منفصلتين لا يحصل عليهما إلا الحساب الذي يتم السماح له بهما.
3) لوحة الصلاحيات أوضح: ✓ يستطيع / ✕ لا يستطيع، شرح واقعي، تجميع حسب الوظيفة، زر مشاهدة فقط، وصلاحيات ZKTeco ضمن مجموعة منفصلة.
4) تسجيل الدخول لم يعد يعيد تحميل الصفحة بعد نجاح كلمة السر؛ يتم تحميل بيانات الحساب مرة واحدة وفتح اللوحة مباشرة.
5) تسجيل الخروج يعطي استجابة فورية، يحفظ العمليات المعلقة بأمان، ثم ينهي الجلسة بدون الانتظار الثابت القديم 900ms.

بيانات التشغيل:
- لم تُصفّر قاعدة البيانات ولم تُغير .env أو APP_KEY أو storage أو vendor.
- ZKTecoRealtimeTest يبقى ملف فريق IT الأصلي بدون تعديل.
