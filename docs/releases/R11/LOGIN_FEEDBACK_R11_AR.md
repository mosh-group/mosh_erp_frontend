# MOSH ERP R11 — حالة تحميل تسجيل الدخول

## التعديل
- زر «دخول» يتحول فوراً إلى «جارٍ تسجيل الدخول…» مع مؤشر دوران.
- نموذج الدخول يحمل aria-busy ويظهر رسالة حالة «جاري التحقق من بيانات الدخول…».
- تعطيل الزر وحقول اسم المستخدم/كلمة السر وخيار الحفظ وزر إظهار كلمة السر أثناء الطلب.
- منع إرسال طلب دخول ثانٍ إذا تكرر الضغط أو Enter أثناء وجود الطلب الأول.
- عند فشل الدخول/الاتصال يعاد بناء النموذج بحالته الطبيعية وتظهر رسالة الخطأ كما كانت.
- عند النجاح يبقى المؤشر حتى إعادة تحميل التطبيق المعتادة.

## نطاق التغيير
لا تغيير في API أو صلاحيات الدخول أو Business Logic أو بيانات المستخدمين أو Backend.
ملفات التشغيل المتغيرة في Frontend: index.html و api-map.json و css/styles.css و js/43-mosh-auth-v37-js.js فقط.

## الفحص
- اختبار Chromium بحالة رد login متأخر: ظهر التحميل، وأُرسل طلب login واحد رغم طلب الإرسال مرتين، ثم عاد الزر لحالته الطبيعية عند 401 بلا JavaScript page errors.
- إعادة اختبار R10: صفر preload warnings وصفر preload nodes، وكل 60 ملف manifest طُلب مرة واحدة وبنفس الترتيب مع async=false.
- Node tests الحالية: 38 نتيجة ناجحة.
- فحص صياغة JavaScript: 63 ملفاً، دون أخطاء.
