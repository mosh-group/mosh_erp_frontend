# MOSH ERP — R17 — الصلاحيات والضبط وتسريع الدخول والخروج

## التعديلات
- فصل صلاحية «ضبط المظهر والخطوط» عن «إعدادات النظام الكاملة» وعن «تعديل الصلاحيات».
- الحساب الذي يملك ضبط المظهر فقط يرى الخط والأحجام والألوان وراحة الواجهة، ولا يرى إدارة الحسابات/الصلاحيات أو سياسات HR أو هوية النظام.
- الحساب الذي يملك إدارة الحسابات/الصلاحيات فقط يستطيع فتح لوحة الحسابات دون منحه ضبط المظهر.
- حماية Backend تمنع صاحب صلاحية المظهر من تغيير اسم النظام أو الشركة حتى لو حاول إرسال طلب يدوي.
- إعادة تنظيم محرر صلاحيات المستخدم: مجموعات واضحة، شرح واقعي لكل صلاحية، وصف لما يحتويه كل قسم، زر «مشاهدة فقط»، وتجميع صلاحيات ZKTeco في مجموعة قابلة للفتح.
- تسجيل الدخول بعد نجاح كلمة السر لم يعد يعيد تحميل الصفحة كاملة؛ يجلب bootstrap مرة واحدة ويحدّث الحالة داخل الصفحة.
- تسجيل الخروج يعطي استجابة بصرية فوراً، يحفظ أي عملية معلقة، ينهي الجلسة ثم يعيد الصفحة بدون انتظار 900ms الثابت السابق.

## السبب الجذري للبطء
- الدخول السابق: POST /auth/login ثم location.reload ثم GET /auth/status ثم GET /bootstrap وإعادة تحميل/تنفيذ الواجهة.
- الخروج السابق: انتظار flush ثم POST /auth/logout ثم انتظار ثابت 900ms ثم reload.
- R17 ألغى reload من مسار الدخول، وألغى انتظار 900ms من الخروج مع إبقاء flush الآمن قبل إنهاء الجلسة.
