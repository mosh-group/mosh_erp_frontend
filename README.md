# MOSH Workdesk R4 — employee announcements at the top

Start with **WORKDESK_R4_README_AR.md** for installation and the self-recipient read-receipt backend checks. See **WORKDESK_R4_QA.md** for the actual test scope.

This is the full Vanilla frontend built on R3. It preserves the API connection configuration, task/work-time logic and five-minute reminder, and moves employee notifications above attendance. No production server or database has been modified. The standalone preview is for demonstration only and is not the deployment entry point.

The earlier R2/R3 documents are retained as historical documentation, including the time-report backend contract. General setup and original API schemas are in SETUP.md and API_DOCUMENTATION.md.
